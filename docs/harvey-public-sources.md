# Fontes públicas de referência

Este documento registra as fontes públicas que inspiraram a arquitetura e a estrutura do repositório Sopa da Vovó.

## Harvey AI

### Harvey LAB
- Repositório: https://github.com/harveyai/harvey-labs
- Tipo: benchmark jurídico aberto
- Foco: agentes legais, tarefas reais, rubricas, execução e avaliação
- Observação: estrutura mais próxima de um benchmark operacional completo

### BigLaw Bench
- Repositório: https://github.com/harveyai/biglaw-bench
- Tipo: benchmark para tarefas jurídicas e profissionais
- Foco: categorias transacionais, litigiosas, retrieval e workflows
- Observação: útil para categoria de tarefas e metodologia de avaliação

### Deep Research Starter
- Repositório: https://github.com/harveyai/deep-research-starter
- Tipo: starter para pesquisa aprofundada via API
- Foco: workflow de investigação e síntese de pesquisa
- Observação: útil para integrações de pesquisa profunda

## Outras referências públicas relevantes

- Harvey org public repos: https://github.com/harveyai
- Repositórios podem ser usados como referência para infraestrutura, processamento de documentos e integração de ferramentas.

## Como utilizamos essas referências

- não copiamos conteúdos completos;
- não clonamos arquivos sem autorização quando fora do escopo público;
- usamos a estrutura e o conceito de benchmark como referência para adaptar uma solução própria;
- priorizamos documentação, arquitetura, métricas, tarefas e pipelines próprios.

## Objetivo neste projeto

Transformar essas referências em:
- uma base didática;
- uma implementação mínima e funcional;
- uma estrutura extensível para agentes legais e benchmarks internos.
